Maahu AI Digital Private Limited · Architecture

Applied AI & Cloud Infrastructure for Circular Fashion.

Maahu is engineered in India on Google Cloud as an AI-first wardrobe intelligence and trust platform — combining multimodal garment vision, policy-grounded conversational AI, cryptographic identity verification, and an immutable financial ledger.

Core AI Systems

Four Production Pillars Beyond Peer-to-Peer Rental

Every garment uploaded to Maahu enters an automated AI enrichment, asset-valuation, and verification pipeline built for high-value Indian ethnic and occasion wear.

Google Cloud Vertex AI · Closet Analysis

Multimodal Garment Vision

Behind a private Cloud Run worker, Vertex AI analyzes uploaded garment imagery to infer canonical categories, subcategories, occasion suitability, and care context — eliminating manual catalog entry.

  • Direct signed uploads to private Google Cloud Storage
  • Asynchronous WebP thumbnail, preview, and full CDN variants
  • Human-in-the-loop confirmation before listing publication
RAG Assistant · Policy Grounded

Tara Virtual Concierge

Tara answers member questions on temporary lehenga/blouse alterations, dry cleaning, size fit, security deposit timelines, and payout mechanics with explicit citations.

  • Retrieval-augmented policy responses with verifiable citations
  • Context-aware escalation to Maahu support teams
  • Consistent guidance across onboarding, browsing, and checkout
Wardrobe Economics · INR Analytics

Closet Financial ROI Engine

Transforms personal wardrobes into quantified assets. Tracks total closet value in INR, cost-per-wear, utilization ratios, and projected rental yield across owned garments.

  • Decimal-safe INR / paise financial computation
  • Idle wardrobe capital identification
  • 1-tap closet item conversion to community rental listing
Trust & Zero-Knowledge KYC

Aadhaar Secure QR & Evidence Chain

Cryptographic UIDAI-signed QR verification gates marketplace transactions without collecting selfies, paired with photo-documented handover and return checkpoints.

  • UIDAI XML/QR signature validation on backend
  • Short-lived signed playback URLs for private dispute evidence
  • Scheduled retention cleanup & legal hold controls
Google Cloud Stack · asia-south1

Hybrid Data Authority & Zero-Trust Mobile

Built natively in Mumbai (asia-south1) with Terraform-managed infrastructure, strict separation between dev and prod, and OpenAPI-contracted mobile clients.

Compute & AI Orchestration
Cloud Run + Vertex AI Workers

Node.js / TypeScript Express APIs and private background workers running on Cloud Run with zero Vertex credentials exposed to mobile clients.

System of Record
Cloud SQL (PostgreSQL) Ledger

Server-authoritative pricing, booking state machines, Razorpay order verification, idempotent webhook reconciliation, deposits, payouts, and audit logs.

Real-Time Conversations
Cloud Firestore + Cloud Storage

Real-time renter–lender threads, handover checklists, read receipts, and malware-scanned private evidence media stored separately from public CDN assets.

Client & Security Boundary
Flutter + Firebase App Check

Cross-platform iOS and Android client generated from authoritative OpenAPI contracts, protected by Firebase Phone Auth, App Check attestation, and Terraform IaC.
